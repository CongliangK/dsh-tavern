# 从剧本、小说与素材中提取新人物卡

可以从小说、剧本或素材中抽取人物与相关设定，制作新卡。

## 在哪里

界面：从剧本新建人物卡 / Agent

## 如何使用

1. 选择“从剧本新建人物卡”，提供一份或多份素材。
2. 说明要提取谁、需要哪些背景与关系，以及不想带入的内容。
3. 与 Agent 核对提取和改编方案，确认后制作人物卡。

## 结果与生效范围

得到基于素材的新人物卡，供后续编辑与游玩。

## 注意事项

选中素材不等于一次读完整本小说；需要的范围应说明清楚。
