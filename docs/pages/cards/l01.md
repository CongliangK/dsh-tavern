# 谨慎使用外部预设

默认建议保留内置预设。调整文风、叙事方式和写作规则时，优先修改人物卡或使用 Guide。

## 在哪里

界面：预设库

## 如何使用

1. 在卡片模式中把长期写作要求写入人物卡，或在游玩中通过 Guide 注入本局要求。
2. 在预设库保持“不使用外部预设（默认）”。
3. 只有明确了解外部预设的提示词、正则和行为影响时，才选择启用。

## 结果与生效范围

常规写作要求由人物卡或 Guide 承担；外部预设仅在明确选择时参与下一轮前台请求。

## 注意事项

外部预设可能改变系统行为，效果也可能与原酒馆不同。后台 Agent 不运行外部预设，工作台中的引用仅供阅读编辑。
