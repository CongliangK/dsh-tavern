# 按个人喜好修改世界书、预设和剧本

世界书、预设和剧本也可以通过自然语言修改。

## 在哪里

界面：合并起始任务「修改剧本 / 世界书 / 预设」/ Agent

## 如何使用

1. 选择「修改剧本 / 世界书 / 预设」并挑一个目标。
2. 指出不喜欢的背景、写作规则或剧情，说明修改方向与保留范围。
3. 查看建议并确认，让 Agent 修改工作版。
4. 在对应资源库检查结果。

## 结果与生效范围

不用逐个手写字段，也能调整一份资源的内容。

## 注意事项

不同资源生效范围不同。世界书和预设有直接编辑表单；剧本与素材库正文查看页不是文本编辑器。
