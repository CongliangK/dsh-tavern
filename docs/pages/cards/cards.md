# 卡片模式

把不合口味的内容改成自己喜欢的样子。人物卡、世界书、预设和剧本，都可以通过对话来制作与修改。

## 认识卡片工作台

卡片模式不是游戏正文窗口，而是与 Agent 一起处理资源的工作台。选择要做的任务，在中间讨论修改，在右侧查看和引用资源。

| 界面区域 | 用途 |
| --- | --- |
| 起始任务 | 新建人物卡（逐题问答）、修改人物卡、温和改写、转成 MVU 版、从剧本制卡、创建写作 Skill，修改世界书、预设或剧本；空白开始 |
| 中间对话 | 说明要求、讨论方案，确认后让 Agent 写入修改 |
| 右侧资源库 | 管理人物卡、世界书、剧本、预设、正则、Guide、长期偏好、改卡记忆、Skill 和系统提示词 |
| 工作台历史 | 继续之前的制作与修改，与游玩历史分开管理 |

## 通过对话修改不喜欢的内容

1. 选择修改任务和目标资源。
2. 告诉 Agent 哪些内容不喜欢，希望怎样调整，以及哪些设定要保留。
3. 查看建议，确认修改范围后再写入工作版。
4. 查看修改结果；人物卡可新开一局体验。

例如：“保留人物的身份和背景，但把过于强势的性格改得更克制。先告诉我你准备改哪些地方。”

这套方式同样适用于世界书、预设和剧本，不只是人物卡。

## 从小说和剧本中提取新卡

选择一份或多份素材，说明想提取的人物、相关设定和保留范围。与 Agent 讨论、确认后制作新人物卡，不需要从零填写所有字段。

## 资源库：在右侧查找、管理和复用内容

在卡片模式打开右侧对应标签页。没有显示时，从右侧的新建标签页入口选择需要的库。库中保存的是可复用资源；选中查看、引用到对话、应用到游戏是不同操作。

### 人物卡库

保存角色设定，是开局和改卡的入口。可以批量导入 PNG / JSON，搜索与筛选卡片，查看、编辑字段，管理世界书和剧本绑定，重命名、删除或导出 JSON。

要让 Agent 修改，先引用目标卡，再说清修改要求；要开始游戏，从卡片新建游玩。修改工作版不等于所有旧游戏已同步更新。详见[人物卡字段](#i02)与[原版恢复](#h09)。

### 世界书库

管理独立世界书和人物卡内置世界书。可搜索、导入、导出、查看和编辑条目，调整启用状态与触发条件，管理人物卡关联，也可引用给 Agent 修改。可以把常用的世界书设为全局世界书，它和人物卡绑定的世界书合并使用，同一本只加载一次。

世界书存放故事背景与规则，不是已经发生的游戏记忆。保存高级字段不等于完整执行原酒馆全部规则。详见[世界书库](#j01)。

### 剧本与素材库

保存小说、故事大纲和写作教学材料。可导入、查看、重命名、删除和引用素材，也可以把剧本绑定到人物卡。

引用素材可以交给 Agent 抽取人物、修改剧本或[创建写作 Skill](#m04)；只有绑定剧本并用于开局，才是剧本游玩的来源。查看页用于阅读，正文修改交给 Agent。详见[导入素材](#k01)。

### 预设库

管理外部提示词方案。可导入、导出、重命名、删除，编辑提示词条目的内容、角色、顺序和开关，以及预设正则。

“新游戏默认预设”用于之后开局；正在玩的游戏在顶栏“本局设置”选择预设。默认可以不使用外部预设，外部预设可能明显增加思考时间和延迟。详见[预设编辑](#l03)与[正则编辑](#l04)。

### 长期偏好库

保存多份长期偏好，例如分别用于轻松日常和严肃剧情。通过“查看长期偏好”选择库中项目，用“新建”“重命名”管理名称；进入访谈建立长期偏好，或查看、编辑已确认内容。

在库中切换查看或保存修改，不会自动改变当前游戏。当前游戏使用哪份长期偏好，在“本局设置”中选择；库中内容更新后，可在那里检查版本并应用最新内容。新游戏默认使用方式与本局选择分开。详见[长期偏好完整教程](#e01)。

### Skill 库

保存 Agent 可重复使用的方法。可以导入 SKILL.md 或 Skill 文件夹的压缩包。列表区分内置与自建 Skill，按用途分组；可以拖动调整用途，点击名称阅读正文及参考资料，也可编辑、预览、保存或删除。

写作 Skill 用于指导前台表达，其他 Skill 用于对应任务。库中管理方法和用途，本局设置控制当前游戏的写作 Skill 开关；关闭后不会删除已载入历史的内容。详见[创建写作 Skill](#m04)与[Skill 管理](#m05)。

### 正则库与 Guide 库

正则库把全局、本局预设和人物卡自带的正则放在同一页：全局规则可以新建、导入、启用/停用和排序，立即生效；预设与人物卡只显示本局来源，开关只影响本局，不改写来源文件。旧版导入的正则会迁入全局并默认停用。Guide 库保存常用的 Guide 方案，可删除单条或整个方案。

### 系统提示词库

管理程序开放给用户调整的内置提示词。选择条目查看和编辑，保存后用于相应生成流程；可导入、导出整套 JSON，或恢复默认。

它与外部预设库不同，也不是本局 Guide。更新程序保留自行保存的修改，但主动导入整套配置或恢复默认会覆盖相应自定义内容，操作前可先导出备份。普通文风要求优先放在 Guide 或人物卡，不熟悉内置规则时保持默认。详见[系统提示词](#l05)。

## 引用、绑定和修改有什么区别

引用是把资源交给当前工作台讨论；绑定是让资源与人物卡建立使用关系；修改则会改变对应工作版。引用到对话，不等于已经绑定到游戏。

导入时保留人物卡原版，日常修改工作版。需要恢复时，可请 Agent [恢复人物卡原版](#h09)；这不是所有资源都具备的任意版本恢复功能。
