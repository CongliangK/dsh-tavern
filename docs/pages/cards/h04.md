# 修改人物卡中不喜欢的内容

不用先懂卡片字段，也可以把不喜欢的设定改得更合口味。

## 在哪里

界面：修改人物卡 / Agent

## 如何使用

1. 选择“修改人物卡”和目标卡。
2. 说明不喜欢什么、希望怎么调整、哪些内容必须保留。
3. 先查看修改建议，确认后让 Agent 修改工作版。
4. 检查结果，再新开一局体验。

## 结果与生效范围

现有人物卡保留你喜欢的部分，同时按要求调整。

## 注意事项

修改会改变工作版，不应默认覆盖原版；不要把“讨论建议”当作已经保存。
