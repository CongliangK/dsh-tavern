# 引用多个资源协作创作

多份资源可以放进同一工作台对话，供 Agent 对照使用。

## 在哪里

界面：资源库 → 在对话中引用

## 如何使用

1. 在人物卡、世界书、预设或剧本与素材库选择资源。
2. 使用“在对话中引用”加入当前卡片对话。
3. 说明每份资源的用途，例如保留角色、借用背景或比较文风。

## 结果与生效范围

Agent 可以按需读取这些材料来讨论或修改。

## 注意事项

引用不等于绑定到游玩，也不代表立刻修改了资源。
