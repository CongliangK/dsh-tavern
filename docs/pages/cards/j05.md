# 管理世界书与人物卡的绑定

人物卡可以绑定多本世界书，同一本世界书也可以被多张卡复用。

## 在哪里

界面：世界书 / 人物卡

## 如何使用

1. 在人物卡详情展开世界书，点击列表下方的“＋ 新增绑定”，选择世界书后确认绑定。
2. 通过上移、下移调整顺序；第一本是主书，可以逐本打开或解绑。
3. 从人物卡新开局，使用当前绑定；已有世界书快照的存档保持原有内容。

## 结果与生效范围

开局时把各本内容合成一份本局世界书，游玩中的脚本修改保存在本局。

## 注意事项

多本世界书可能相互冲突，引发异常。
