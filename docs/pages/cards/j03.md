# 编辑世界书与条目

世界书编辑器可管理名称、说明和各个条目。

## 在哪里

界面：世界书编辑器

## 如何使用

1. 打开需要修改的世界书。
2. 新增、编辑或删除条目，调整条目启用状态。
3. 检查修改内容并保存。

## 结果与生效范围

保存后的世界书按启用状态和召回规则参与使用；进行中的游戏在下一轮自动采用最新内容，不必手动同步。

## 注意事项

不要把未保存的表单内容当作正式生效；复杂调整可以先交给 Agent 讨论。
