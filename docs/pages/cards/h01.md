# 选择工作台起始任务

工作台先选择任务，再通过对话处理资源。

## 在哪里

界面：新建卡片工作台对话

## 如何使用

1. 新建卡片工作台对话。
2. 选择起始任务：新建人物卡（逐题问答确定角色与开场，可选 MVU 变量和前端美化，先看 HTML 草图再建卡）、修改人物卡、人物卡温和改写（被模型拒绝输出时改写为温和版本）、把人物卡转成 MVU 版、从剧本新建人物卡、创建写作 Skill，或修改剧本 / 世界书 / 预设；也可空白开始。
3. 选择目标资源，说明想做的修改。

## 结果与生效范围

任务与资源进入当前 Agent 对话，便于直接开始讨论。

## 注意事项

长期偏好只从右侧栏进入，不是这里的起始任务。卡片 Agent 创作或修改的人物卡会在创作者备注里署名 DSH Tavern。
