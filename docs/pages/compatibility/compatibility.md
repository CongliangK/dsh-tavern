# 酒馆生态兼容

已有的人物卡、世界书和预设，可以从这里继续使用。先了解支持范围，再按需要查看具体操作。

## 可以带来哪些资源

| 资源或能力 | 可以做什么 | 继续阅读 |
| --- | --- | --- |
| 人物卡 | 导入 PNG / JSON，查看、编辑，导出 JSON | [导入人物卡](#i01) |
| 世界书 | 导入背景设定，编辑条目并关联人物卡 | [认识世界书库](#j01) |
| 预设 | 检查和管理外部提示词与正则 | [谨慎使用外部预设](#l01) |
| 正则与前端美化 | 处理正文格式，展示 HTML 内容和人物卡面板 | [正则与 HTML](#d08) |
| MVU | 后台更新变量，在右侧持续展示状态栏 | [MVU 状态栏](#d02) |
| 聊天记录 | 从选卡界面的“导入存档”导入 SillyTavern 聊天记录（.jsonl），作为一局新游戏接着玩 | [导出与导入存档](#n02) |

## 支持范围怎么理解

能导入一张卡，不等于它依赖的全部第三方脚本都能执行。我们分别说明资源的导入、编辑、展示和运行支持，不用“全面兼容”代替具体条件。

- 人物卡支持 PNG 导入和 JSON 导出，目前不提供 PNG 导出。
- 世界书保留部分高级字段，不等于完整复现原酒馆的全部触发规则。
- 正则、MVU 和前端美化取决于人物卡的结构，以及所依赖的脚本和宿主接口。
- 默认建议使用内置预设。要调整文风和写作规则，优先修改人物卡或使用 Guide；外部预设可能改变系统行为。

## 从哪里开始

有喜欢的人物卡，可以直接进入[游玩模式](#play)。如果想修改其中不喜欢的内容，再进入[卡片模式](#cards)。

如果正文中的状态栏经常掉格式，可以按需[转换为 MVU 版](#h07)。正常工作的卡不需要转换。
