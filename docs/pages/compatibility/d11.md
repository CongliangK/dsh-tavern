# 酒馆生态兼容总览

把人物卡、世界书、预设、正则、MVU 与前端美化放在一起理解，才能判断一份酒馆资源能使用到什么程度。

## 在哪里

指南：资源导入与运行支持

## 如何使用

1. 人物卡支持 PNG / JSON 导入、查看和编辑，导出为 JSON。
2. 世界书和预设可导入、编辑与使用，各有自己的生效范围。
3. 正则、HTML 和 MVU 提供展示与状态能力；具体脚本仍需匹配已支持接口。

## 结果与生效范围

已有资源可以复用，也可以通过卡片模式调整。

## 注意事项

silly 模式已停用，已有存档保留。不保证所有第三方插件或原版运行语义可用。
