# 高级字段与导入保留规则

导入时保留高级字段，是为了保存资源信息，不表示每个字段都完整执行。

## 在哪里

界面：兼容字段 / 指南

## 如何使用

1. 在兼容字段中查看排序、位置、深度、概率、递归等配置。
2. 需要修改时先区分保存字段与实际召回效果。
3. 遇到差异时，结合实际条目与游戏结果检查。

## 结果与生效范围

未知字段和 extensions 等数据可被保留。

## 注意事项

不能据此承诺原酒馆的全部运行语义；silly 模式已停用。
