# 正则美化与 HTML 面板

人物卡中的受支持正则可以处理内容，并将 HTML 展示为正文面板。

## 在哪里

自动：人物卡消息展示

## 怎样参与游玩

1. 导入带有正则或前端美化资源的人物卡。
2. 游玩时查看正文的实际展示结果。
3. 需要检查规则时，在人物卡扩展中查看；需要修改时交给 Agent。

## 结果与生效范围

同一段文本可以按卡片规则转换为更适合阅读的展示。

## 注意事项

HTML 展示不等于所有浏览器脚本或酒馆宿主接口都可运行；应按具体卡片依赖判断。
