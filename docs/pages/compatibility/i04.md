# 查看正则、脚本和扩展数据

人物卡扩展页可以查看正则、Tavern Helper 脚本与其他扩展数据。

## 在哪里

界面：人物卡扩展

## 如何使用

1. 打开人物卡的扩展内容。
2. 阅读具体规则、脚本和关联数据。
3. 需要修改时，将人物卡引用给 Agent 并明确要求。

## 结果与生效范围

可以了解卡片的展示与运行依赖。

## 注意事项

这里主要是只读查看，不是通用可视化脚本编辑器；看到扩展数据不代表它能全部运行。
