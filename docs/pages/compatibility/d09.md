# Tavern Helper 与卡内脚本支持范围

卡内脚本能否工作，取决于它使用的接口，而不只取决于能否导入。

## 在哪里

自动 / 指南

## 怎样参与游玩

1. 查看人物卡中的 Tavern Helper 脚本与扩展。
2. 了解脚本所需的变量、界面联动和宿主接口。
3. 出现问题时连同实际错误交给 Agent 检查。

## 结果与生效范围

可以针对具体依赖确认支持范围，而不是只凭导入成功判断。

## 注意事项

不承诺所有手机、数据库或酒馆插件可用。已有聊天记录遵循 DSH 的历史模型，不等同于原酒馆可任意改写的消息列表。
