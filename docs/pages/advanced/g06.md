# Qwen-Image

Qwen-Image是可选的生图渠道，只需配置自己实际使用的服务。

## 在哪里

界面：生图渠道

## 如何使用

1. 打开场景生图设置，选择该渠道。
2. 选择 Qwen-Image 渠道，按具体服务配置认证、模型及参数。
3. 检查连接；确认费用并打开「开启场景生图」后，手动生成一张图片，检查附件是否成功保存。

## 结果与生效范围

配置完成后，可在支持范围内为剧情配图。

## 注意事项

相同模型名称不代表不同服务的接口与能力完全一致。 渠道入口存在不代表这里已逐家实测。
