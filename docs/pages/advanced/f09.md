# 生成失败与保存失败恢复

生成失败与保存失败是两种情况，处理方式不同。

## 在哪里

界面：错误提示 / 重试保存

## 如何使用

1. 先看错误发生在服务生成阶段，还是图片返回后的附件保存阶段。
2. 生成失败时，检查渠道错误，按需重新生成。
3. 图片已生成但保存失败时，使用“重试保存”，不要直接重画。

## 结果与生效范围

图片成功保存并出现在剧情下，才算完成。

## 注意事项

重新生成可能再次收费；重试保存不应被当作重新调用供应商。
