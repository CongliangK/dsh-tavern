# 创建并保存可复用 Skill

Skill 保存可复用的工作方法；写作 Skill 可供前台按场景选择，通用 Skill 可用于其他工作台任务。

## 在哪里

Agent：创建 Skill

## 如何使用

1. 在 Skill 库查看已保存的名称、内容和用途。
2. 需要修改时，向卡片 Agent 说明要改进的方法和边界；可使用 create-skill 流程整理。
3. 按需要调整用途或删除；写作 Skill 的使用开关在本局设置中。
4. 开始匹配的任务，通过轨迹查看是否实际加载。

## 结果与生效范围

用户 Skill 保存在持久数据目录，可供后续任务复用。

## 注意事项

Skill 不是工具权限，也不保证模型必定执行所有要求；避免重复、冲突或过于宽泛的触发条件。
