# 查看与确认生效文本

长期偏好先形成草案，再由你确认，避免把 Agent 的猜测直接变成长期偏好。

## 在哪里

界面：长期偏好

## 如何使用

1. 查看原始回答、偏好分析和拟注入摘要。
2. 指出不准确的地方，让 Agent 修改后重新展示。
3. 确认最新版内容符合你的意思，再明确要求保存确认长期偏好。

## 结果与生效范围

原始回答、草案和已确认长期偏好分开保存；回答问卷本身不会自动确认长期偏好。

## 注意事项

不确定的推断应继续核对。只说“继续”不等于同意保存。
