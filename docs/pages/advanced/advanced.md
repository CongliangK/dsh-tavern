# 高级功能

这些能力不是开局前的必修课。遇到需要解决的问题，再点开相应的说明。

## 七项高级功能，从需要解决的问题出发

| 想解决的问题 | 阅读指南 |
| --- | --- |
| 希望以后开局都符合自己的偏好 | [长期偏好](#e01) |
| 长对话中忘记约定或剧情细节 | [记忆检索](#d06)与[上下文压缩](#d07) |
| 正文、美化或变量结算异常 | [卡片 Agent 调试](#h08) |
| 希望把正文状态栏改为后台变量更新 | [人物卡转 MVU](#h07) |
| 希望把写作教学材料变成可复用方法 | [创建写作 Skill](#m04) |
| 想补充本局重要人物的设定 | [人物档案设计](#d10) |
| 需要现实世界的外部资料 | [联网搜索](#m02) |

先选择与你当前问题相关的一项，不需要全部开启。长期偏好管理长期偏好，历史检索回查本局剧情，联网搜索查询外部资料。

## 记忆与人物

- [历史回忆](#d06)：故事变长后，按需找回已经发生的细节。
- [上下文压缩](#d07)：整理长对话，不等于无限或无损记忆。
- [世界书召回](#d05)：补充预先写好的背景，与回忆游戏历史不同。
- [后台人物设计](#d10)：为本局重要人物设计、补全和复用档案，普通卡与 MVU 卡都可使用。

## 按需要定制

- [状态栏转 MVU](#h07)：正文状态栏反复掉格式时再考虑转换。
- [长期偏好](#e01)：通过访谈整理长期偏好，只在右侧栏主动开启新局默认使用。
- [互联网搜索](#m02)：在本局设置中允许前后台按需查外部资料，后续请求生效。
- [模型分工](#m01)：正文与后台任务可以选用不同模型。
- [系统提示词](#l05)：调整内置生成规则，与外部预设分开管理。

## 创作方法与扩展

- [提炼文风](#m04)：从样文中分析可复用的写法。
- [保存 Skill](#m05)：明确请求后，将方法保存为技能文件。

## 为文字剧情配图

[文生图](#f01)独立于文字游玩，默认关闭，不会自动出图。配置渠道并打开开关后，可在每轮正文下方手动出图、重画、查看版本，以及在支持的渠道中设置人物参考。

生图可能产生额外费用。无需逐个了解所有渠道，选择自己实际使用的服务即可。
