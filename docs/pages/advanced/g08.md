# ComfyUI

ComfyUI是可选的生图渠道，只需配置自己实际使用的服务。

## 在哪里

界面：生图渠道

## 如何使用

1. 打开场景生图设置，选择该渠道。
2. 先准备可用的 ComfyUI 服务，再连接地址、导入工作流并配置参数映射。
3. 检查连接；确认费用并打开「开启场景生图」后，手动生成一张图片，检查附件是否成功保存。

## 结果与生效范围

配置完成后，可在支持范围内为剧情配图。

## 注意事项

酒馆连接已有服务，不负责自动安装模型、节点或修复第三方工作流。 渠道入口存在不代表这里已逐家实测。
