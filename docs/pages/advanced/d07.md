# 压缩长对话上下文

上下文压缩把长对话整理成摘要，减少后续直接携带的内容；原始剧情记录仍用于回查。

## 在哪里

界面：压缩操作

## 如何使用

1. 空闲时从游玩“更多”菜单发起压缩，等待前后台各自的处理结果。
2. 若希望自动执行，打开设置 → DSH Tavern → 上下文压缩。
3. 选择手动（默认）、每 N 轮自动压缩，或上下文达到 X% 自动压缩；按轮可设 1–1000，百分比可设 10–95%。需要时调整“压缩后保留最近几轮原文”（0–100，默认 10）。
4. 点击“保存压缩设置”，在下一个安全边界生效。自动模式在剧情后台结算后协调前后台压缩。
5. 压缩后继续游戏；遗漏具体细节时，让 Agent 使用历史检索回查原文。

## 结果与生效范围

前台和后台分别整理上下文，结果分别显示；前台摘要按固定的八段结构整理，并把最近几轮原文（默认 10 轮，可在设置里改）附在摘要之后。压缩不删除原始剧情记录。

## 注意事项

压缩可能遗漏细节并影响缓存，不宜频繁执行。重写同一轮、工具调用和生图不计轮数；百分比是估算，模型窗口未知时可改用轮数模式。前台成功不代表后台也成功。
