# 把游玩问题交给 Agent 调试

正则、前端美化、状态更新或生成效果异常时，可以让卡片 Agent 结合实际游玩证据排查。

## 在哪里

界面：酒馆状态 → 遇到显示或生成问题？ → 交给卡片 Agent 调试

## 如何使用

1. 在出问题的游戏右侧酒馆状态中，展开“遇到显示或生成问题？”，点击“交给卡片 Agent 调试”。
2. 进入工作台后，检查任务中的目标人物卡和“已关联游玩记录”引用。
3. 补充发生轮次、实际现象和预期效果，例如：“第 8 轮正文正常，但状态栏仍是上一轮，请检查。”再发送任务。
4. Agent 可使用 tavern_read_play_chat 先读 overview，再按需检查日志、状态和相关资源。
5. 查看原因与修改内容，按需要应用修改，再用原来的操作验证是否恢复。

## 结果与生效范围

调试与问题游戏关联，Agent 可以依据记录分析，而不只是根据一句报错猜测。

## 注意事项

点击入口只是准备调试任务，不等于修复完成。资源修改也不代表旧游戏已经自动更新。持续失败时保留诊断包；验证正常后再继续长局。
