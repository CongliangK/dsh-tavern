# 修改长期偏好与继续访谈

口味改变时可以修订长期偏好，不必重做完整问卷。

## 在哪里

界面 / Agent

## 如何使用

1. 在长期偏好中查看当前偏好文本。
2. 直接修改已确认偏好，或进入 Agent 访谈，说明具体想修改的部分。
3. 通过访谈修订时，检查新的草案，再确认保存。

## 结果与生效范围

之后启用长期偏好的新游戏使用新的已确认版本。

## 注意事项

修改长期偏好库不会自动替换已有游戏的版本。要改本局长期偏好，可在“本局设置”的“长期偏好”中选择，从下一轮生效；切换会影响缓存。
