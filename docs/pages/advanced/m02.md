# 联网搜索

联网搜索让 Agent 按需查阅外部资料；卡片工作台还可整理作品资料与网页出处。

## 在哪里

界面：本局设置 → 联网搜索

## 如何使用

1. 在全局设置 → 卡片工作台搜索中选择搜索源与回退顺序。内置 Bing、DuckDuckGo，也可填写自己的 SearXNG 实例与引擎。默认直连，高级设置支持搜索代理与各源覆盖。
2. 点击“保存并测试搜索”检查当前网络；已选择的第三方搜索后端会保留，也可点“使用内置搜索”切回。
3. 游玩时在顶栏“本局设置”开启“联网搜索”，前后台按任务需要使用；前台工具可单独关闭。
4. 需要读取网页原文时，开启全局“允许读取网页正文”；网页读取沿用 DSH 网页服务与代理设置。
5. 在卡片工作台提出：“查找这部作品的人物设定，附来源并区分原文与搜索摘要，再整理补卡建议。”资料工具最多搜索 3 条关键词、读取 3 个网页，不直接修改人物卡。

## 结果与生效范围

搜索结果保留来源；工作台资料包区分已读取正文与仅搜索摘要，并标注时间、缓存状态和截断情况。

## 注意事项

免费源可能限流或失效；未默认配置公共 SearXNG 实例或代理。网页读取不自动运行浏览器，需登录或依赖脚本的页面可能读不到正文。已读取也不等于已核实，应核对来源和设定冲突。回忆本局剧情请用历史检索。
