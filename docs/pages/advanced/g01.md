# OpenAI Images 与同协议服务

OpenAI Images 与同协议服务是可选的生图渠道，只需配置自己实际使用的服务。

## 在哪里

界面：生图渠道

## 如何使用

1. 打开场景生图设置，选择该渠道。
2. 填写该服务的地址、认证和图像模型；按模型能力设置画面参数。
3. 检查连接；确认费用并打开「开启场景生图」后，手动生成一张图片，检查附件是否成功保存。

## 结果与生效范围

配置完成后，可在支持范围内为剧情配图。

## 注意事项

同协议的第三方服务不一定完整实现所有参数，需要验证具体模型与参考能力。 渠道入口存在不代表这里已逐家实测。
