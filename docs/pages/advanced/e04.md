# 在右侧栏启用长期偏好

“默认长期偏好”决定之后新开的游戏使用哪一份已确认的长期偏好。

## 在哪里

界面：右侧栏 → 长期偏好 → 默认长期偏好

## 如何使用

1. 先完成长期偏好确认。
2. 在右侧长期偏好面板的“默认长期偏好”下拉框里选中它；也可在“设置 → DSH Tavern”里选。
3. 新开游戏使用这份偏好的当前已确认版本；不想继续默认使用时改回“不启用”。

## 结果与生效范围

每局保留选定的长期偏好版本，长期偏好库修订不会悄悄改变正在玩的游戏。也可在“本局设置”中手动切换本局长期偏好，从下一轮生效。

## 注意事项

默认为“不启用”。保存长期偏好不会自动选中，改回“不启用”也不等于删除长期偏好。
