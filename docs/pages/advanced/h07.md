# 状态栏掉格式时，转换为 MVU 版

正文内状态栏反复掉格式，或希望把变量更新交给后台时，可以把人物卡转成 MVU 版。

## 在哪里

界面：把人物卡转成 MVU 版 / Agent

## 如何使用

1. 在卡片工作台选择“把人物卡转成 MVU 版”，选择目标人物卡；默认直接改这张卡，想保留原卡时先说明，Agent 会先复制一份。
2. 说明需要保留哪些状态字段、初始值和变化规则；检查 Agent 的转换方案。
3. Agent 按 card-to-mvu 流程拆分变量初值、后台更新规则与只读状态栏，并保留图片和人物设定。
4. 用转换后的卡新开一局，检查初始状态栏。
5. 进行一轮会改变状态的行动，等待后台结算，对照变量回执和右侧状态是否更新。

## 结果与生效范围

剧情生成与变量更新分开，状态栏依据变量展示；转换结果需要实际游玩验证。

## 注意事项

正常工作的卡无需转换。不是任意第三方脚本都能自动适配，也不能只凭文件保存成功就认定转换完成。
