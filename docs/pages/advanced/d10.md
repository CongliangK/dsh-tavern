# 人物档案设计

人物档案设计用于为本局的重要人物创建、补全和复用设定，普通卡和 MVU 卡都可使用。

## 在哪里

界面：酒馆状态 → 人物设计档案 → 设计人物

## 如何使用

1. 打开右侧酒馆状态，找到“人物设计档案”。
2. 空闲时点击“设计人物”，填写要求，例如：“补充这位店主的动机、说话方式和与主角的关系，保留已经发生的剧情。”
3. 也可留空，让后台根据当前剧情和已有档案设计，再点击“开始设计”。
4. 等待“设计中…”结束，点击人物名称展开身份、别名和各项设计内容。
5. 失败时查看提示，使用“重试设计”；补充设计时明确要修改哪个人物及保留什么。

## 结果与生效范围

设计前先检查本局世界书；已有完整人物设定时直接复用，页面会提示未重复建立档案。新设计保存在本局人物档案，并写入绑定的世界书、自动同步到本局：新人物在下一轮正文强制带入一次，之后以姓名和别名触发、按需召回，无需再次允许同步。档案可逐条删除，会一并移除本局世界书里为该人物生成的条目（手动改过的保留）。多本绑定时写入主世界书，未绑定时创建人物卡内置世界书。人物卡本身的改动仍需手动允许同步；对应条目正文若被手动修改，会提示冲突并保留修改。

## 注意事项

生成或后台忙碌时不可发起。人物姿势是当前场景状态，档案是人物设计；设计中的未来可能性不等于已经发生。普通卡不会因此自动拥有 MVU 状态栏。
