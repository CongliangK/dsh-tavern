# NovelAI

NovelAI是可选的生图渠道，只需配置自己实际使用的服务。

## 在哪里

界面：生图渠道

## 如何使用

1. 打开场景生图设置，选择该渠道。
2. 选择 NovelAI，填写账号认证，并设置渠道提供的模型与画面选项。用自定义渠道时新建接入点、填它的地址和 Key：接口和官方一样的选「官方格式」，用对话接口出图的选「对话格式」。还可以设置正面和负面提示词、采样参数与固定种子，保存提示词预设，并在画师串库里点选带预览图的画师串。
3. 检查连接；确认费用并打开「开启场景生图」后，手动生成一张图片，检查附件是否成功保存。

## 结果与生效范围

配置完成后，可在支持范围内为剧情配图。

## 注意事项

账号权限、额度与费用由供应商决定，不能用文字模型配置代替。官方免费账号不能通过 API 生图。 渠道入口存在不代表这里已逐家实测。
