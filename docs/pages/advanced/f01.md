# 开启并配置场景生图

文字游玩不依赖插画。想配图时，再配置并开启场景生图。

## 在哪里

界面：设置 → 场景生图

## 如何使用

1. 打开场景生图设置，选择实际使用的渠道。
2. 填写服务地址、认证与模型等该渠道需要的信息。
3. 确认服务费用和隐私范围后，打开「开启场景生图」，在想配图的那一轮点击图片图标手动生成。

## 结果与生效范围

可以手动为剧情发起插画生成。

## 注意事项

默认关闭，开启后也只在你点击时请求。生图服务可能单独收费；不要把文字模型密钥与生图服务配置混为一谈。
