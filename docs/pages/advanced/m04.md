# 创建写作 Skill

把写作教学材料整理成场景写作 Skill，让前台在合适的情节中参考其中的方法。

## 在哪里

Agent：引用写作教学材料 → 明确要求创建 Skill

## 如何使用

1. 在“剧本与素材库”导入并引用需要使用的教学材料到卡片工作台。
2. 明确提出：“根据这份材料创建写作 Skill，说明适用场景和不适用场景。”仅导入或阅读不会自动创建。
3. 核对提取的写法、例子和适用边界，避免把所有场景都套成同一种文风。
4. 让 Agent 保存；create-writing-skill 会将必要方法写入完整正文，默认分配给前台并允许模型按场景调用。
5. 在 Skill 库检查内容和用途，在本局设置中开启写作 Skill，再进行适合该方法的剧情。

## 结果与生效范围

模型根据场景选择并加载 Skill，轨迹中的实际加载可用于确认是否调用；保存成功不代表每轮都会使用。

## 注意事项

现成教学材料用于提取方法。若只是提供样文，应先分析、核对写法，再明确要求保存。Skill 指导表达，不改写人物事实或玩家选择。
