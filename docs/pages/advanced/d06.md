# 按需找回历史细节

历史检索用于找回本局已经发生的细节。压缩保留主要线索，检索在需要时补回原文，两者配合管理长对话记忆。

## 在哪里

自动：历史检索工具

## 怎样参与游玩

1. 正常游玩时由 Agent 按需回查，不必每轮手动要求检索。
2. 发现记错时，提供人物、事件关键词或大致轮次，例如：“查一下之前和店主约定的时间，再继续。”
3. Agent 使用 tavern_recall_history 按关键词找相关轮次，或读取指定轮次附近的原文。
4. 在轨迹中可查看实际调用；若结果不相关，补充更准确的事件线索。

## 结果与生效范围

模型可以参考已保存的历史正文，而不必一直把所有细节留在直接上下文中。

## 注意事项

每次生成最多召回 6 次；完整正文召回后冷却 10 个剧情轮次，前后台分别管理。检索不保证必定命中，也不能把旧事件当作新剧情重演。它不查互联网或长期偏好。
