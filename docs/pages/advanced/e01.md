# 通过访谈建立长期偏好

长期偏好保存你认可的长期游玩与写作偏好，适合希望不同人物卡都更符合自己口味的玩家。

## 在哪里

界面：右侧栏 → 长期偏好 → 开始建立长期偏好 / Agent

## 如何使用

1. 打开右侧“长期偏好”，从长期偏好入口进入访谈。可以说：“帮我整理长期游玩偏好，先问我问题，再给我确认。”
2. 按主题回答问题，例如故事基调、叙事视角、描写密度、推进速度和不喜欢的套路。可以自由回答或跳过，不必被参考选项限制。
3. 阅读 Agent 整理的草案，纠正误解，删除不希望长期保留的内容，再明确确认保存。
4. 保存后回到长期偏好面板，按需要在“默认长期偏好”里选中它，再新开游戏。

## 结果与生效范围

已确认的偏好可以跨人物卡复用。面板中可查看长期偏好及实际用于游戏的偏好文本。

## 注意事项

保存长期偏好不等于启用；“默认长期偏好”默认为“不启用”。单局要求用 Guide，人物设定写进人物卡，剧情经过通过历史记录回查，三者不要混在长期偏好里。
