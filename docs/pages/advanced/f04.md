# 重新构思画面与同方案重画

不满意一张插图时，可以重新构思画面，也可以沿用原方案再画一张。

## 在哪里

界面：插画 → 重画

## 如何使用

1. 在插图上选择“重新构思画面”：生图 Agent 放弃原方案，重新决定画哪一幕、怎么构图。
2. 或选择“同方案重画”：沿用原画面方案，只重新出图。
3. 打开大图，展开“画面方案”，可以直接修改提示词后重画，这一步不经过文字模型。
4. 较早轮次没有插图或生图失败时，可在对应位置补画或重试。

## 结果与生效范围

新的图片作为同段剧情的一个插画版本。

## 注意事项

每次重画都会产生新的生图请求，可能再次计费；不是只重试保存。
