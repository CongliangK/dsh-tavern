# 选择画风与画面尺寸

画风决定画面表达，尺寸与比例取决于所选渠道。

## 在哪里

界面：设置 → 场景生图

## 如何使用

1. 打开设置 → 场景生图，在画风里选择“自动”或“锁定画风”。
2. 自动：每张图由 AI 写画风，第一张按这张卡的题材定，之后参考本局上一张保持连续；可在“画风偏好（选填）”里写偏好，例如偏日系、低饱和。
3. 锁定画风：在“锁定的画风”里写好画风，每张图原样使用，AI 不改。
4. 按渠道提供的选项设置尺寸、比例或分辨率；NovelAI、SD WebUI / Forge 等渠道另有负面提示词、步数和 CFG 等高级设置，保存后用于下一次生图和重画。

## 结果与生效范围

后续请求使用这些绘图要求；大图的“画面方案”里可以看到这张图用的画风。

## 注意事项

各渠道可用参数不同，不保证所有模型接受相同尺寸或风格控制。
