# 启动、停止与重新打开

命令行版自行管理服务，桌面版由官方 DeepSeek Harness 管理。

## 在哪里

指南：命令行管理 / DSH

## 如何使用

1. 命令行版可使用 `dsh-tavern start`、`dsh-tavern stop`、`dsh-tavern restart` 管理启停。
2. 关闭网页后，可用 `dsh-tavern open` 重新打开。
3. 用 `dsh-tavern status` 查看状态与完整访问地址。

## 结果与生效范围

可以区分网页关闭与后台服务停止。

## 注意事项

完整访问地址可能含鉴权 token，请勿分享。桌面版不要混用这些服务管理命令。
