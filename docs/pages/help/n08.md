# 常见问题与支持范围

先确认问题发生在哪个环节，再查看对应说明。

## 在哪里

指南

## 如何使用

1. 鉴权或无法打开：使用完整访问地址，确认服务已运行。
2. 正文失败：检查文字模型配置与服务返回的错误。
3. 状态失败：查看变量回执，按需单独重试。
4. 资源缺失：检查人物卡和关联文件是否仍存在。
5. 图片失败：区分生成失败和保存失败。
6. 提示“这不是酒馆故障”：模型拒绝继续或服务商内容审核拦截了这一轮，修改输入后重新发送，或回退后换个写法。

## 结果与生效范围

不同故障有各自入口，不需要用重装解决所有问题。

## 注意事项

第三方服务、不同平台和卡内脚本各有支持范围；没有验证前不承诺完全兼容。

## 如何绑定多个世界书？

在人物卡详情的世界书区域，点击列表下方的“＋ 新增绑定”，选择世界书后点击“确认绑定”。已绑定的世界书按顺序列出，点击书名可以打开，也可以调整顺序或逐本解绑。同一本书可以被多张人物卡使用。

新开局时，系统将这些书合为一份本局世界书，以第一本作为主书。已有世界书快照的存档保持原有内容；导出人物卡会包含合并后的世界书。

多本世界书可能相互冲突，引发异常。系统不会自动协调设定或初始化变量冲突；需要整理时，可以让卡片 Agent 协助[修改世界书](#h06)。操作入口见[世界书绑定](#j05)。

## 为什么没有独立的 user 人设？

作者认为，把 user 人设作为跨人物卡的统一设定，也是原酒馆的设计失误。玩不同人物卡时，玩家可以扮演完全不同的人：这张卡里是侦探，另一张卡里可以是学生，身份、背景和人物关系应当跟随具体人物卡。

建议通过卡片 Agent，把想扮演的 user 人设写入人物卡。例如：“我想在这张卡里扮演一名初来小镇的医生，请把我的身份、背景和与其他角色的关系写入人物卡。”具体操作见[修改人物卡](#h04)。

如果希望长期保留叙事风格、互动方式等个人偏好，可以使用[长期偏好](#e01)。建立并确认长期偏好后，在右侧长期偏好面板的[默认长期偏好](#e04)里选中它，让新游戏注入这些长期偏好；已有游戏不会自动变化。
