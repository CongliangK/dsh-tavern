# 帮助与维护

安装、数据和排错的辅助说明。遇到问题时查阅，不需要按顺序阅读。

## 遇到问题时

先查看并复制具体错误，再选择对应的处理方法。清除提示不等于修复问题；连接成功也不等于真实生成一定成功。

- 正文或展示异常：[交给卡片 Agent 调试](#h08)。
- 状态没有更新：[查看回执](#d03)，按错误提示[重试结算](#d04)。
- 图片失败：[区分生成失败与保存失败](#f09)。
- 需要反馈：[导出排错日志](#n04)，分享前检查私人剧情与配置。
