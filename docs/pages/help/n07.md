# 数据位置、备份与重新安装

命令行版的运行时、配置和游戏数据独立保存在 ~/.dsh-tavern/；官方桌面版和 Android APK 使用各自独立的数据目录。

## 在哪里

指南

## 如何使用

1. 确认自己的宿主、Profile、数据目录和自定义安装位置。
2. 按宿主管理方式停止正在运行的服务，再备份 Profile 数据及自定义内容。
3. 重新安装或更新时保持原来的目录配置，完成后检查资源与对话。

## 结果与生效范围

重要数据有独立副本，不只依赖程序更新时的保留行为。

## 注意事项

更新保留数据不代表删除可自动恢复，也不是云同步。不同安装环境路径不同，不要直接套用别人的目录。
