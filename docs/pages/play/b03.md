# 设置与修改玩家称呼

玩家称呼是故事中如何称呼你，不是长期偏好。

## 在哪里

界面：开局 / 玩家称呼操作

## 如何使用

1. 开场准备中填写姓名、昵称或身份；不填时使用默认称呼。
2. 确认开场预览中的称呼。
3. 游玩中需要调整时，使用玩家称呼操作修改。

## 结果与生效范围

当前游戏使用你设置的玩家称呼。

## 注意事项

玩家人设随人物卡设定：可以让卡片 Agent 把本局玩家的身份、背景和关系写入人物卡。长期游玩与写作偏好则使用长期偏好。修改称呼不等于重写人设或历史剧情。
