# 查看剧本进度并选择继续位置

酒馆状态里的剧本进度按块列出剧本，可以指定下一轮从哪一块继续，并调整每轮推进字数。

## 在哪里

界面：酒馆状态 → 剧本进度

## 如何使用

1. 打开右侧酒馆状态的剧本进度，按块查看剧本位置与内容；用翻页或“跳到第 N 块”找到想要的位置。
2. 在某一块上点“从这里继续”，下一轮从这一块开始读剧本。
3. 需要时展开推进字数设置，填写每轮推进字数并保存，默认 500，可设为 100–10000 的整数；调整后全文重新切片，原文阅读位置不变。

## 结果与生效范围

每个游玩会话可自行控制剧本读到哪里和推进节奏。

## 注意事项

字数按汉字计数，尽量在句末或段落末切分；生成或结算期间不能修改。“从这里继续”只改变下一轮参考的剧本位置，不会改写已经写好的正文。
