# 持续 Guide

Guide 保存当前游戏持续生效的剧情、写作或数值要求。

## 在哪里

界面：酒馆状态 → Guide

## 如何使用

1. 打开酒馆状态中的 Guide。
2. 添加明确要求，例如“本局放慢感情推进，少用旁白总结”。
3. 后续可查看、添加或删除这些指导。

## 结果与生效范围

正文、候选生成和后台变量结算都会使用当前有效的 Guide；涉及数值尺度的要求（如“好感度涨得慢一点”）会在变量结算时遵循。

## 注意事项

Guide 针对本局，不是跨局长期偏好；修改它不会自动改写已经发生的故事。
