# 阅读正文、思考过程与复制消息

正文区用来阅读故事，并在需要时查看模型返回的思考内容。

## 在哪里

界面：消息区域

## 如何使用

1. 阅读当前正文，按人物卡的展示方式查看内容。
2. 思考过程和上下文注入默认隐藏；要查看时，在设置 → DSH Tavern 关闭“隐藏上下文注入和思考过程”，之后按需展开或折叠。
3. 需要复用自己的输入时，使用用户消息的复制操作。

## 结果与生效范围

可以把阅读正文和查看过程分开。

## 注意事项

只有模型实际返回思考内容时才能显示；默认隐藏或模型没有返回时都看不到，不要当作生成故障。
