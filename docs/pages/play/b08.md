# 回退当前回合

回退用于撤回当前回合；正在生成时会先停止前台，后台尽力取消和恢复。

## 在哪里

界面：回合操作

## 如何使用

1. 打开输入框上方的“更多”菜单，选择“回退本轮”。
2. 确认要回退的是眼前这轮内容，再执行。
3. 查看回退后的正文与状态，重新输入行动。
4. 回退错了，可以在“更多”菜单选“撤销回退（恢复第 N 轮）”恢复正文和状态；之后有新的操作，这个恢复点就失效。

## 结果与生效范围

在回退后的有效剧情基础上继续游玩。

## 注意事项

正文回退不等待后台任务退出。后台状态与正文可能不同步；历史快照或后台消息无法恢复时会尽力继续，回退后请检查状态。不提供任意历史节点的存档树，也不要把回退当作数据备份。
