# 认识界面

先按当前任务认识界面，不必一次记住所有面板。

## 在哪里

指南

## 如何使用

1. 左侧：找到游玩历史或卡片工作台历史，继续已有对话。
2. 中间：游玩时阅读正文和输入行动；卡片模式中与 Agent 讨论资源。
3. 右侧：游玩时查看酒馆状态；卡片模式中查看并操作资源库。

## 结果与生效范围

围绕“找对话 → 阅读或讨论 → 查看状态或资源”使用界面即可。

## 注意事项

人物卡自身会影响正文美化和状态栏外观；不是每张卡都有相同的数值面板。
