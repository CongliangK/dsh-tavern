# 完成第一次游玩

第一次游玩只需要一张人物卡和一个可用的文字模型。

## 在哪里

界面：新建游玩

## 如何使用

1. 导入 PNG / JSON 人物卡，选择新建游玩。
2. 预览开场白；有多个开场时前后切换选择。
3. 按需要填写故事中的玩家称呼，确认开场。
4. 阅读正文后直接输入行动，或点选候选追加到输入框、修改后发送。

## 结果与生效范围

你会得到新的故事正文，并可继续下一轮。

## 注意事项

长期偏好不在开场准备中。生图、外部预设、系统提示词和其他高级功能都可以先跳过。
