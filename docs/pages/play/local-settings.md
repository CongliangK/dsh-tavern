# 本局设置

在游玩顶部调整当前游戏，已有对话与变量保留。

## 本局设置：只调整正在玩的这局

入口在游玩顶部“本局设置”，打开后显示在右侧。大多数选项修改后自动保存，玩家称呼在离开输入框后保存；留意保存反馈。已有对话和变量保留。

| 分组 | 设置 | 用途与生效范围 |
| --- | --- | --- |
| 游玩 | 玩家称呼 | 修改后用于后续内容，不重写已有正文 |
| 游玩 | 当前预设 | 为本局选择外部预设，或不使用外部预设；影响后续正文 |
| 游玩 | 长期偏好 | 选择已确认长期偏好或不使用长期偏好，下一轮生效；可展开核对本局实际内容，库中有更新时可应用最新版本 |
| 游玩 | 状态栏位置 | 状态栏显示在侧边栏或正文下方 |
| 模型 | 后台模型与推理强度 | 选择独立模型或跟随前台；下一次后台任务生效，正在执行的任务不变 |
| 模型 | 生图 Agent 模型 | 整理插图画面、写绘图提示词用的模型；默认跟随前台（此时用最低推理强度，出图更快），也可单独选模型和推理强度；下一次生图生效 |
| 功能 | 变量结算 | 只在 MVU 卡显示；控制后台 MVU 更新，关闭后变量和状态栏不再更新 |
| 功能 | 人物姿势 | 每轮总结人物位置、动作和姿势，供前台保持一致，并显示在酒馆状态里 |
| 功能 | 联网搜索 | 允许本局前后台按需查外部资料，后续请求生效 |
| 高级（默认折叠） | 写作 Skill | 控制本局后续可加载的写作方法，不删除已经加载到历史中的内容 |
| 高级（默认折叠） | 插件 | 本局用到的第三方插件：按局开关、选择由谁负责结算、调整结算任务先后、查看最近错误 |

切换预设、长期偏好、模型、推理强度或相关任务与工具配置可能使提示词缓存失效，首次请求会增加耗时和费用。无需为了每轮剧情频繁改设置；临时写作要求可以使用 [Guide](#b09)。
