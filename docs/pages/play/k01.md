# 导入小说、剧本和素材

小说、剧本和大纲可以作为素材导入，再用于游玩或制卡。

## 在哪里

界面：剧本库

## 如何使用

1. 在剧本与素材库导入 TXT、Markdown、JSON 或 EPUB。
2. 查看导入后的工作版内容。
3. 按用途选择绑定人物卡，或引用到工作台。

## 结果与生效范围

素材进入资源库，可以按需读取与处理。

## 注意事项

人物卡内直接导入剧本的入口只支持 TXT、Markdown、EPUB，不包含 JSON。
