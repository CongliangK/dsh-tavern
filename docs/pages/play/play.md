# 游玩模式

从第一局开始，认识眼前的界面和操作。无需先学会所有设置，也不用先制作自己的卡。

## 开始第一局

1. 完成安装，在 DSH 中配置文字模型服务。
2. 导入一张 PNG 或 JSON 人物卡，选择新建游玩。
3. 预览开场白，按需要选择开场并设置玩家称呼。
4. 输入自己的行动，或选择一个候选、修改后发送。

没有外部预设也能开始；长期偏好、生图和后台独立模型都可以先不管。

## 认识游玩界面

| 界面区域 | 在这里做什么 |
| --- | --- |
| 左侧历史 | 找到并继续已有游戏，管理对话 |
| 中间正文 | 阅读故事，查看当前回复和正文操作 |
| 输入框与候选 | 输入行动和对白，选择、修改或重新生成候选 |
| 右侧酒馆状态 | 查看 Guide、人物状态，以及已绑定剧本的进度 |

## 玩过几轮之后

- [重新生成候选](#b06)：换一组行动建议，不改写已经生成的正文。
- [重写正文](#b07)：直接重新生成，或填写意见后重写当前回复。
- [回退当前回合](#b08)：退回当前回合，不是任意历史节点的存档树。
- [Guide](#b09)：为当前游戏添加持续生效的要求，正文、候选和变量结算都会参考。
- [人物状态](#d01)与[变量回执](#d03)：查看本轮结果；结算失败可单独重试。
- 游玩台账：右侧状态面板里的玩家备忘录，分物品、角色、地点。平时不更新，点“更新游玩台账”时由后台整理上次之后的新剧情；整理后下一轮正文会参考一次台账。
- [撤销回退](#b08)：回退错了，可以从“更多”菜单恢复。

## 跟随一份剧本游玩

导入小说、大纲或剧本，绑定人物卡后新开一局。故事会参考当前进度附近的片段，你仍然可以自由行动、偏离主线。

右侧[剧本进度](#c03)按块列出剧本，可以点“从这里继续”指定下一轮从哪里读。

## 本局设置

点击游玩顶部“本局设置”，调整本局称呼、预设、长期偏好、后台模型和功能开关。[打开本局设置完整说明](#local-settings)。

## 全局设置：通用显示、压缩与生图服务

入口：左下角“设置” → “DSH Tavern”。这里管理通用选项，以及“新游戏默认”：前台、后台、生图 Agent 和卡片工作台的默认模型，默认玩家称呼、状态栏位置和各项后台结算开关，只影响之后新开的游戏。正在玩的游戏在上方介绍的本局设置中调整。

### 正文分色

开启后，引号内对白与斜体分别着色，普通文字保持原色，保留人物卡已有配色。点击色块设置对白和斜体颜色，“恢复默认配色”恢复自动适配深浅背景的颜色。

颜色修改即时应用，只保存在当前浏览器，不改变存档或发给模型的文字，也不跨设备同步。

### 上下文压缩

默认手动，也可选择每 N 轮自动压缩，或上下文达到指定百分比时自动压缩。轮数范围为 1–1000，百分比范围为 10–95%，百分比是估算。

修改后点击“保存压缩设置”，下一个安全边界生效。自动压缩在剧情后台结算后协调前后台，不删除原始剧情记录。重写同一轮、工具调用和生图不计轮数；模型窗口未知时可改用轮数模式。详见[压缩与检索配合](#d07)。

### 生图服务配置

入口：左下角“设置” → “场景生图”，与“DSH Tavern”页分开。在提供场景生图能力的版本中，配置渠道、服务地址、密钥及对应参数，按渠道检查连接或读取模型。这里设置的是服务连接，不会给每局自动生成图片；保存完整配置后打开「开启场景生图」（全局，默认关闭），每轮正文下方才出现图片图标，点击手动生成。详见[生图配置](#f01)。

### DSH 自身设置

文字模型服务在“设置 → 模型”配置；语言、外观、字号及 Desktop Profile 等由 DSH 对应设置页管理。它们与插件的“系统提示词库”不是同一个入口。皮肤选择和壁纸设置见[皮肤与外观](#appearance)。

## 保存和继续故事

通过左侧[历史对话](#n01)继续游玩。[导出](#n02)菜单里，“故事正文”保存玩家与角色的正文用于阅读，“存档”可以在别的机器或重装后导入继续玩；SillyTavern 的聊天记录也能从选卡界面的“导入存档”导入。日志导出用于排错，与这两种导出不同。
