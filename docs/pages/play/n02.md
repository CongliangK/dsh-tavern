# 导出故事与存档

导出有三种：故事正文用于阅读，存档用于换机器或备份后继续玩，日志用于排错。

## 在哪里

界面：导出操作 / 导入存档

## 如何使用

1. 在游玩顶部打开导出菜单。
2. 选择“故事正文”：得到 Markdown，有配图时是 zip，解压后 Markdown 与 images 文件夹放在一起，配图插在对应正文之后。
3. 选择“存档”：得到 .dshsave 文件，包含这局的正文、回退历史、人物卡、配图，以及插件保存的数据和挂的媒体；在选卡界面的“导入存档” → “DSH Tavern 存档（.dshsave）”导入，作为一局新游戏继续玩。
4. 从 SillyTavern 带来的聊天记录，在“导入存档” → “SillyTavern 聊天记录（.jsonl）”导入，接着玩。

## 结果与生效范围

故事正文适合阅读和分享，存档可以在另一台机器或重装后接着玩。

## 注意事项

导入的存档是一局新游戏，不会覆盖原来的游戏；插件数据要在装了同一插件的酒馆里才会被用上。排错请使用日志导出。
