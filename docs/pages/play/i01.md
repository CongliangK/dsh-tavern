# 导入与导出人物卡

人物卡支持 PNG / JSON 导入，导出为 JSON。

## 在哪里

界面：人物卡库 / 选卡器

## 如何使用

1. 打开人物卡库或选卡器，选择导入。
2. 选择 PNG 或 JSON 人物卡文件，导入后查看内容。
3. 需要保存或分享卡时，使用 JSON 导出。

## 结果与生效范围

导入的卡可以编辑、用于新开局，或引用到卡片工作台。

## 注意事项

PNG 导入能力不等于 PNG 导出能力；导入成功也不代表卡内所有脚本可执行。
