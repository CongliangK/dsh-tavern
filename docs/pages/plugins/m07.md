# 安装酒馆插件

在设置里粘贴插件的 GitHub 地址就能安装酒馆插件，不用找数据目录，也不用敲命令。

## 在哪里

界面：设置 → DSH Tavern → 插件

## 如何使用

1. 打开酒馆 → 设置 → 酒馆插件。
2. 把插件作者给的 GitHub 地址（形如 https://github.com/作者/仓库）粘贴进输入框，点「安装」。有 Release 时安装最新 Release，否则安装默认分支。
3. 连不上 GitHub 时，在插件仓库页面点 Code → Download ZIP 下载，再在同一处点「上传 ZIP」。
4. 安装完成后刷新页面。列表里显示「已加载」就是装好了；显示「加载失败」时会写出原因，可以把它发给插件作者。
5. 从 GitHub 装的插件会自动检查更新，也可以点「已装的插件」旁的「检查更新」重查；有新版时显示「更新到 x.y.z」，已经是最新版时显示「已是最新」，不会一直提示更新。更新会把插件换成新文件，但 DSH 仍运行旧版本，需要重启 DSH 才生效（刷新页面只更新浏览器侧）；点「删除」会把插件文件夹移到 plugin-backups 备份目录。
6. 不想让某个插件运行时点「停用」，插件文件和设置都会保留，想用时再点「启用」；想手动放文件夹的，点「打开插件文件夹」，把插件文件夹整个放进去即可。

## 结果与生效范围

插件随酒馆一起加载，在每一局都生效；停用后在所有游戏里都不再运行。

## 注意事项

插件会运行在你的电脑上，只装信任的作者发布的插件。依赖 npm 包又没把依赖打包进去的插件不能一键安装，会直接提示，按作者的说明手动装。人物卡自带的插件由人物卡库管理，在卡片详情里停用。这里装的是 DSH Tavern 插件，不是 SillyTavern 扩展。自己写插件见[插件开发：常见用法](#plugin-recipes)和[接口总览](#plugin-api)。
