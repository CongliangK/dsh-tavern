# 插件

给酒馆加功能：在设置里粘贴插件的 GitHub 地址就能装。想自己写插件，看后面两篇开发文档。

## 装插件只要一步

打开酒馆 → 设置 → DSH Tavern → 插件，粘贴插件的 GitHub 地址，点「安装」，刷新页面。详细步骤、更新提示、启用/停用和删除见[安装酒馆插件](#m07)。

## 去哪找插件

- [Discord 交流群](https://discord.gg/hYAEjKnpra)：作者在这里分享和讨论插件。

## 自己写插件

- [插件开发：常见用法](#plugin-recipes)：按要做的插件找写法，配图、记忆、读变量、后台推演、接管结算。
- [插件开发：发布与一键安装](#plugin-publishing)：怎样发布，别人才能在设置里粘贴地址一键安装。
- [插件开发：接口总览](#plugin-api)：插件怎么写、怎么拿到接口，以及分页的接口说明。
